# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. This project showcases my skills, projects, and contact information in a clean and user-friendly design.

## 🚀 Features

* Responsive Design
* Modern Hero Section
* About Me Section
* Services Section
* Portfolio / Projects
* Why Choose Me
* Frequently Asked Questions (FAQ)
* Testimonials
* Contact Section
* Smooth Navigation
* Clean & Organized Code

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Font Awesome
